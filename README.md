# portfolio-simple

Portofolio statis Alca W44. HTML, CSS, dan JS murni — tanpa framework, tanpa dependency, tanpa build step.

## Menjalankan

Buka `index.html` langsung di browser, atau jalankan server statis:

    python3 -m http.server 8080

## Struktur

| File | Fungsi |
| --- | --- |
| `index.html` | Struktur halaman: hero, proyek, stack, kontak |
| `style.css` | Tema Crafted Dark Obsidian, layout, responsif |
| `script.js` | Nav mobile, scroll-spy, filter proyek, salin email |
